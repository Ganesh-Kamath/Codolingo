## Brand & Style

This design system embodies "Algorithmic Mastery & Forward Momentum" — delivering an experience reminiscent of an elite aerospace or high-frequency engineering terminal turned flight academy. It treats software craftsmanship as high-performance aviation, replacing typical juvenile gamification metaphors (cartoon chests, bubbly coins, soft badges) with precision telemetry, linear milestones, and luminous computational feedback.

### Target Audience & Emotional Impact
- **Audience:** Ambitious software engineers, systems programmers, and technical learners seeking mastery over fundamentals and complex architectures.
- **Impression:** Ruthlessly competent, laser-focused, empowering, and razor-sharp. The interface evokes the stillness of high-altitude night flight combined with the electric immediacy of a live deployment.

### Aesthetic Paradigm: Cybernetic Precision & Dark Flight Telemetry
- **Architectural Dark Core:** Deep, cold obsidian and navy surfaces (`#0A0D14`, `#101524`) provide infinite visual runway and absolute contrast without optical fatigue.
- **Laser-Etched Illumination:** Electric hyper-cyan serves as the prime kinetic vector, indicating compilation success, active circuits, and velocity.
- **Deep Syntax Resonances:** Controlled bursts of vivid violet/purple symbolize abstract intelligence, algorithmic depth, and mastery tiers.
- **Structural Integrity:** Fine 1px ghost borders, structural graticules, and micro-metric indices guide the eye with mathematical discipline.

## Colors

The palette establishes an aggressive, high-contrast dark environment optimized for extended IDE sessions and focused problem-solving.

### Core Swatches
- **Primary (`#00F5D4` — Hyper Cyan):** The pulse of the system. Used for forward momentum, active states, execution controls, and real-time telemetry markers.
- **Secondary (`#7928CA` — Syntax Violet):** Signifies deep algorithmic knowledge, master ranks, structural tags, and high-tier milestone achievements.
- **Tertiary (`#09E5B8` — Quantum Mint):** Secondary affirmative states, optimized unit tests, and performance benchmarks.
- **Neutral Surface Floor (`#0A0D14` — Obsidian Core):** The baseline canvas that eliminates backlight glare and establishes maximum dynamic range.

### Architectural Canvas Stack
- **Surface Level 0 (Base/Runway):** `#0A0D14` — Deepest canvas floor.
- **Surface Level 1 (Panels & Trays):** `#101524` — Base card backgrounds and split panes.
- **Surface Level 2 (Elevated Nodes):** `#161D31` — Active cards, hover states, and flyouts.
- **Surface Level 3 (Overlays & Modals):** `#1E2640` — Focus modals and HUD viewports.

### Contrast & Boundaries
- **Hairline Boundary:** `#1F293D` at 100% or `rgba(248, 250, 252, 0.08)`.
- **Active Edge Glow:** `rgba(0, 245, 212, 0.35)` to highlight the current active terminal or compilation scope.
- **Text Matrix:**
  - **Primary Text:** `#F8FAFC` (High-contrast Off-White)
  - **Secondary Text:** `#94A3B8` (Slate Mid-tone)
  - **Tertiary / Telemetry Dim:** `#475569` (Muted Vector Gray)

## Typography

The typography system operates on a functional tripartite hierarchy:

1. **Space Grotesk (Display & Architecture):** Delivers clean, engineered authority with subtle algorithmic idiosyncrasies in display scales. Used strictly for mission banners, track titles, and module heads.
2. **Inter (Interface & Pedagogical Prose):** Provides high legibility across instructional material, challenge descriptions, and navigational elements. Designed to be transparent and neutral.
3. **JetBrains Mono (Telemetry, Syntax & Vector Data):** Bridges code execution with achievement statistics. Every numerical score, execution latency counter, memory footprint metric, and code block relies on this monospace engine for vertical tabular alignment.

### Typographic Discipline
- Always pair uppercase micro-headers (`telemetry-micro`) with tracking (`letter-spacing: 0.08em`) to mimic aerospace instrument clusters.
- Maintain tabular lining figures in monospaced components so progress meters, counters, and clock timers do not cause layout shifts during live execution.

## Layout & Spacing

The layout model uses a dense, technical cockpit architecture built around a flexible 12-column workspace grid. Spacing is governed strictly by a base-4 vertical rhythm, prioritized for dense data feeds, split-pane IDE layouts, and real-time telemetry panels.

### Form Factors & Adaptation Rules
- **Desktop (1280px+):** Fixed side-dock navigation (64px collapsed, 240px expanded). Central content operates in a 12-column workspace with a minimum 24px gutter. Supports a tri-pane layout: Exercise Tree (col 1–3), Editor & Terminal (col 4–9), Live Diagnostics & Progress Telemetry (col 10–12).
- **Tablet (768px - 1279px):** Reflows into dual-pane vertical viewports. Diagnostic sidebar docks to a collapsable bottom sheet. Gutters compress to 16px.
- **Mobile (< 768px):** Single-column stack. Code viewports transition to read-execute focus with floating action overlays. Side panels collapse into off-canvas navigation panels.

### Rhythm Discipline
- Keep component interior padding tight (`space-sm` to `space-md`) to reinforce the professional cockpit density.
- Section boundaries employ clean horizontal graticule rules (`1px solid #1F293D`) instead of loose whitespace buffers.

## Elevation & Depth

This design system rejects conventional blurry drop shadows in favor of **structural luminescent layering**, combining architectural surface steps, calibrated ghost strokes, and directional laser blooms.

### Surface Hierarchy
1. **Bedrock (`#0A0D14`):** The non-interactive background. Zero elevation.
2. **Structural Tier (`#101524`):** Main workbench panels and non-focused code containers. Encased with a `1px` subtle outline in `rgba(248, 250, 252, 0.07)`.
3. **Elevated Instrument (`#161D31`):** Hovered challenge cards, running terminals, active step cards. Border highlights to `rgba(248, 250, 252, 0.16)`.
4. **Focused State / Active Flight Layer (`#1E2640`):** Modal dialogues, telemetry overlays, and executing pipelines.

### Kinetic Glow System
- **Focus / Success Glow:** No fuzzy gray shadows. Instead, active elements project a coherent directional beam:
  `box-shadow: 0 0 0 1px #00F5D4, 0 4px 20px rgba(0, 245, 212, 0.15)`
- **Violet Authority Glow:** Applied during rank advancement, mastery unlocks, and tier completion:
  `box-shadow: 0 0 0 1px #7928CA, 0 4px 24px rgba(121, 40, 202, 0.25)`
- **Backdrop Blurs:** Flyouts and elevated HUD overlays implement `backdrop-filter: blur(12px)` over 85% alpha surfaces (`rgba(16, 21, 36, 0.85)`).

## Shapes

The design system employs a **Soft Technical (Level 1)** geometric silhouette. Radii are kept intentionally compact (`0.25rem` / `4px` baseline) to prevent the interface from appearing toy-like or juvenile.

### Architectural Rules
- **Standard Controls & Micro-Nodes:** `rounded` (4px / 0.25rem). Used for buttons, input fields, code tags, and telemetry badges.
- **Panels & Structural Modules:** `rounded-lg` (8px / 0.5rem). Applied to code editors, exercise cards, and modal windows.
- **No Pill Radii:** Full pill radiuses (`9999px`) are forbidden on standard components, reserved strictly for live state indicators (e.g., blinking real-time connection status or terminal socket LEDs).
- **Beveled Corner Accents:** Decorative HUD panels and elite mastery achievements may incorporate a 45-degree `clip-path` notch (4px–6px) on top-right corners to enforce the aerospace telemetry aesthetic.

## Components

### Buttons & Interactive Triggers
- **Primary Kinetic Action:** Background `#00F5D4`, text `#0A0D14` with font `Space Grotesk` weight 600. Sharp 4px radius. On hover, background shifts to `#09E5B8` with a tight, vibrant cyan outer glow (`0 0 16px rgba(0, 245, 212, 0.4)`).
- **Secondary Telemetry Action:** Background `#101524`, border `1px solid rgba(248, 250, 252, 0.12)`, text `#F8FAFC`. On hover, border turns to `#00F5D4` and text tracks forward.
- **Mastery Action:** Background `#7928CA`, text `#F8FAFC`. Used exclusively for exam submissions, final builds, and certification claims. Hover yields `#9D4EDD` with violet halo.

### Progress Telemetry & Status Badges (Gamification)
- **Mastery Badges:** Geometric, polygon-inspired vectors. Clean 1px metallic framing, with internal vector iconography rendered in JetBrains Mono or geometric lines. No gold coins or comic shields.
- **Linear Telemetry Bars:** High-density progress tracks. Height of 4px–6px with background `#161D31`. Active fill is a high-velocity gradient from `#7928CA` to `#00F5D4`. Completed segments include vertical separator ticks evoking aerospace fuel gauges.
- **Status Chips:** Low-opacity background (`rgba(0, 245, 212, 0.1)`), 1px stroke (`rgba(0, 245, 212, 0.3)`), text in `#00F5D4` rendered via `JetBrains Mono` at 10px uppercase with `0.08em` tracking.

### Code Editor & Interactive Terminals
- **Workbench Chassis:** Base surface `#101524` wrapped in `1px solid #1F293D`. 
- **Header Graticule:** File names and active branch rendered in `JetBrains Mono` 12px with a persistent 2px cyan active indicator tab line on top.
- **Line Gutter:** Muted line numbering `#475569`, current active line highlighted in bold off-white `#F8FAFC` accompanied by a faint cyan surface tint (`rgba(0, 245, 212, 0.04)`).

### Input Fields & Controls
- **Field Anatomy:** Dark fill (`#0A0D14`), `1px solid #1F293D` border, 4px radius. Text `#F8FAFC`, placeholder `#475569`.
- **Active State:** Border snaps to `#00F5D4` with zero transit lag; zero-blur offset glow.
- **Checkboxes & Radios:** Angular 4px squares (and 4px diamonds for radio selectors). Unchecked state features an inset `#101524` fill. Checked state renders a solid `#00F5D4` center with `#0A0D14` structural tick.

### Cards & Modules
- **Modular Data Cards:** Encased in `#101524` with fine ghost edges. Cards reveal an upper 1px progressive highlight along the top border (`border-top: 1px solid rgba(0, 245, 212, 0.4)`) on hover, indicating active track progression.
- **Flight Diagnostic HUD (Telemetry Summary Card):** Modular grid displaying real-time metrics (e.g., Code Velocity, Algorithmic Efficiency, Memory Profile) using large tabular figures from `JetBrains Mono` over tiny uppercase labels.
